# Jak sprawdzić auto w bezpłatnej usłudze „Historia Pojazdu” i OC w UFG

> Do wydruku (A4). Historia Pojazdu to bezpłatna usługa państwowa na portalu gov.pl, oparta na danych z Centralnej Ewidencji Pojazdów (CEP). Zakres i wygląd wyniku mogą się zmieniać – opis poniżej jest ogólny.

## Krok 1. Zdobądź trzy dane od sprzedawcy

| Dane | Gdzie je znaleźć | Wpisz |
|---|---|---|
| Numer rejestracyjny | tablice, dowód rejestracyjny (pole A) | |
| Numer VIN (17 znaków) | dowód rejestracyjny (pole E), tabliczka znamionowa, pod szybą | |
| Data pierwszej rejestracji | dowód rejestracyjny (pole B) | |

Bez kompletu trzech danych usługa nie pokaże wyniku. Prośba o te dane jest normalna – uczciwy sprzedawca zwykle je podaje. Jeśli auto nie jest jeszcze zarejestrowane w Polsce, usługa go nie znajdzie (wtedy patrz krok 7).

## Krok 2. Otwórz właściwą stronę

- Wpisz w wyszukiwarce: **„Historia Pojazdu gov.pl”** i wybierz serwis w domenie **gov.pl**.
- Usługa jest **bezpłatna** i nie wymaga logowania. Strony z podobną nazwą, które żądają opłaty, to serwisy komercyjne.

## Krok 3. Wpisz dane i sprawdź wynik

- Wpisz numer rejestracyjny, VIN i datę pierwszej rejestracji dokładnie tak, jak w dowodzie (VIN nie zawiera liter I, O, Q).
- Jeśli wynik się nie pojawia – sprawdź literówki; nadal brak wyniku = poproś sprzedawcę o zdjęcie dowodu rejestracyjnego (z zasłoniętymi danymi osobowymi).

## Krok 4. Co zawiera wynik

- [ ] **Dane techniczne**: marka, model, rok produkcji, pojemność i moc silnika, rodzaj paliwa – porównaj z ogłoszeniem.
- [ ] **Oś czasu**: pierwsza rejestracja (także informacja, czy pierwsza rejestracja była za granicą), rejestracja w Polsce, zmiany właściciela.
- [ ] **Liczba właścicieli/współwłaścicieli** w Polsce – porównaj z deklaracją „pierwszy właściciel” lub „jeden właściciel”.
- [ ] **Badania techniczne**: daty i wynik, **odczyty drogomierza**.
- [ ] **Ubezpieczenie OC**: czy jest ważne.
- [ ] **Status**: czy auto jest zarejestrowane, wyrejestrowane, czasowo wycofane z ruchu, zgłoszone jako kradzione; ewentualne adnotacje (np. o wymianie licznika).

## Krok 5. Jak czytać przebiegi z badań technicznych

Przepisz odczyty do tabeli i porównaj z licznikiem oraz deklaracją sprzedawcy.

| Data badania / odczytu | Przebieg (km) | Różnica od poprzedniego | Uwagi |
|---|---|---|---|
| | | | |
| | | | |
| | | | |
| | | | |
| Licznik dziś | | | |

Na co zwrócić uwagę:

- [ ] **Każdy kolejny odczyt powinien być wyższy.** Spadek przebiegu jest do wyjaśnienia ze sprzedawcą – przyczyną może być wymiana licznika (powinna być odnotowana), pomyłka przy wpisie albo ingerencja w licznik.
- [ ] **Różnice między latami**: typowo kilkanaście–dwadzieścia kilka tys. km rocznie. Bardzo małe przyrosty lub nagły „przestój” przy aktywnie użytkowanym aucie – do wyjaśnienia.
- [ ] **Ostatni odczyt vs licznik dziś**: przebieg na liczniku nie może być niższy niż przy ostatnim badaniu.
- [ ] **Auto sprowadzone**: odczyty zaczynają się dopiero od badania w Polsce. Przebieg sprzed importu warto potwierdzić dokumentami z kraju pochodzenia lub płatnym raportem historii z zagranicy.
- [ ] Oprócz odczytów z badań w historii mogą pojawić się odczyty zapisane przy innych zdarzeniach (np. kontrolach drogowych).

Wynik przebiegów możesz wkleić do naszego formularza – raport porówna je z deklarowanym przebiegiem.

## Krok 6. Sprawdzenie OC w UFG

- Wpisz w wyszukiwarce: **„UFG sprawdź OC”** i wybierz stronę Ubezpieczeniowego Funduszu Gwarancyjnego.
- Podaj numer rejestracyjny lub VIN oraz datę, na którą sprawdzasz.
- [ ] Wynik pokazuje, czy auto ma ważne OC i w jakim zakładzie ubezpieczeń.
- [ ] Brak OC = auto nie może legalnie wyjechać na drogę (również na jazdę próbną).
- [ ] Informacje o szkodach z polis OC/AC może pobrać właściciel auta z UFG (po zalogowaniu) – możesz poprosić sprzedawcę o taki wydruk.

## Krok 7. Gdy auto nie jest zarejestrowane w Polsce

- Historia Pojazdu nie pokaże danych sprzed rejestracji w Polsce.
- Poproś o zagraniczne dokumenty: dowód rejestracyjny, historię serwisową, umowę zakupu.
- Rozważ płatny raport historii z zagranicy (dostępne komercyjne serwisy sprawdzające po VIN).

## Podsumowanie wyniku

- [ ] Dane techniczne zgodne z ogłoszeniem.
- [ ] Liczba właścicieli zgodna z deklaracją.
- [ ] Przebiegi rosną, brak spadków; licznik dziś ≥ ostatni odczyt.
- [ ] OC ważne, badanie techniczne ważne.
- [ ] Brak statusu „kradziony”, „wyrejestrowany”, „czasowo wycofany”.

Każdą niezgodność potraktuj jako pytanie do sprzedawcy, nie jako przesądzenie – często ma ona proste wyjaśnienie, które warto jednak udokumentować.
